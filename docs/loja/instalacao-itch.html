You need a Meta Quest and a way to sideload. Nothing after that needs a computer.

1. Install the APK

Download questretro-vr-release.apk above and install it with SideQuest, or over USB with adb install questretro-vr-release.apk.

2. Grant file access — don't skip this

Put the headset on and open QuestRetro. Hold the menu button on the left controller for half a second to open the panel, go to ROMs and tap "Allow access". Android settings will open: find QuestRetro and turn the switch on.

This is the step that confuses everyone, so it's worth knowing why. Your cores and ROMs live in /sdcard, outside the app. That means they survive a reinstall — but the permission does not. Reinstall the APK and you get an app that looks like it lost everything, when it only needs the switch turned back on.

3. Download a core

Menu → Cores. One line per console, each showing its license before the download button. Pick the console you want to play.

The APK ships no cores — the reason is in the description above. Downloads come from libretro's official buildbot, only when you ask.

4. Add your games

Put your ROMs in any folder on the headset — Download works fine. You can copy them over USB, or straight from the Quest's own Files app. The ROMs tab scans storage and builds a list of games.

Sega CD is the only system needing one more file: the Mega CD BIOS, in /sdcard/QuestRetro/system/. That folder appears on its own after step 2. The app can't download it — it's Sega's.

5. Play

Pick a game in the ROMs tab. Hold the menu button any time to open the panel; a short tap is Start.

If something looks wrong

  • "No games found" or "no core loaded" — it's almost always step 2. Check the switch is still on.
  • The Cores page can't download — it needs internet, and it's the only thing in the app that does.
  • Sega CD boots to a black screen — that's the missing BIOS. It fails quietly instead of erroring.
  • Still stuck? Open an issue — say which console and core, and paste the log from adb logcat -s godot.

Português

Você precisa de um Meta Quest e de um jeito de fazer sideload. Depois disso, nada exige computador.

1. Instale o APK

Baixe o questretro-vr-release.apk acima e instale pelo SideQuest, ou por USB com adb install questretro-vr-release.apk.

2. Libere o acesso aos arquivos — não pule

Ponha o headset e abra o QuestRetro. Segure o botão de menu do controle esquerdo por meio segundo para abrir o painel, vá em ROMs e toque em "Permitir acesso". Abrem os Ajustes do Android: ache o QuestRetro e ligue a chave.

É o passo que mais confunde, e vale saber por quê. Seus cores e ROMs ficam em /sdcard, fora do app. Isso faz com que eles sobrevivam a uma reinstalação — mas a permissão não. Reinstalou o APK, aparece um app que parece ter perdido tudo, quando só falta religar a chave.

3. Baixe um core

Menu → Cores. Uma linha por console, cada uma mostrando a licença antes do botão. Escolha o console que você quer jogar.

O APK não traz core nenhum — o porquê está na descrição acima. O download vem do buildbot oficial da libretro, e só a seu pedido.

4. Ponha seus jogos

Deixe suas ROMs em qualquer pasta do headset — Download serve. Dá para copiar por USB, ou direto pelo app Arquivos do próprio Quest. A aba ROMs varre o armazenamento e monta a lista de jogos.

O Sega CD é o único que pede um arquivo a mais: a BIOS do Mega CD, em /sdcard/QuestRetro/system/. Essa pasta aparece sozinha depois do passo 2. O app não pode baixá-la — ela é da Sega.

5. Jogue

Escolha um jogo na aba ROMs. Segure o botão de menu a qualquer momento para abrir o painel; toque curto é Start.

Se algo parecer errado

  • "Nenhum jogo encontrado" ou "sem core carregado" — quase sempre é o passo 2. Confira se a chave continua ligada.
  • A página Cores não baixa — ela precisa de internet, e é a única coisa no app que usa rede.
  • Sega CD abre em tela preta — é a BIOS faltando. Ele falha calado, sem dar erro.
  • Continua travado? Abra uma issue — diga o console e o core, e cole o log de adb logcat -s godot.
